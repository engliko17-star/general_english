# Формат урока

Урок хранится в таблице `lessons`, поле `content`:

```json
{ "blocks": [ { "id": "b1", "type": "text", ... }, ... ] }
```

У каждого блока есть `id` (уникальный внутри урока — по нему сохраняются ответы ученика), `type` и необязательные `title` и `instruction`.

Типы повторяют шаблоны Edvibe, поэтому при переносе каждый шаблон превращается в один блок.

| Тип | Шаблон Edvibe | Проверка |
|---|---|---|
| `text` | Текст, Статья | — |
| `image` | Картинка | — |
| `video` | Видео | — |
| `audio` | Аудиозапись | — |
| `gaps` | Заполнить пропуски | автоматически |
| `gaps_bank` | Пропуски словами из списка | автоматически |
| `test` | Тест | автоматически |
| `essay` | Сочинение | вручную, через Inbox |

## Поля по типам

**text** — `html`: обычный HTML (абзацы, списки, жирный, таблицы).

**image** — `src`, `alt`, `caption`.

**video** — `url`: ссылка YouTube, Vimeo, Google Drive или прямой файл .mp4. Файл в Google Drive должен быть открыт по ссылке («Все, у кого есть ссылка»), иначе ученик его не увидит.

**audio** — `src`: ссылка на .mp3 (обычно из бакета `lesson-media`), `transcript` — необязательный HTML под плеером.

**gaps** — `text` с пропусками в двойных фигурных скобках.
Несколько верных вариантов — через `|`:

```
I {{am going|'m going}} to the cinema tonight.
```

Необязательно: `case_sensitive: true` — учитывать регистр (по умолчанию нет).

**gaps_bank** — такой же `text`, слова для пропусков собираются в банк автоматически. `distractors` — лишние слова для банка.

**test** — `questions`:

```json
{ "q": "She ___ to work by bus.", "options": ["go", "goes", "going"], "answer": [1] }
```

`answer` — номера верных вариантов с нуля. Если верных несколько, ученик выбирает галочками.

**essay** — `prompt` (задание), `min_words` (необязательно).

## Блоки для перенесённых уроков (ProgressMe)

| Тип | Что это |
|---|---|
| `heading` | Заголовок раздела урока (READING, VOCABULARY…). Поле `text`. |
| `gaps_choice` | Выбор варианта в тексте: `{{some*\|any}}`, звёздочкой отмечен верный вариант. |
| `voice` | Устное задание. Записи голоса пока нет, ученик видит задание. |
| `teacher_note` | Заметка для преподавателя. Текст лежит в таблице `lesson_notes`, а не в уроке, поэтому ученику не приходит вообще. |
| `unsupported` | Тип, который не удалось перенести автоматически. Исходные данные сохранены в `raw`. |

Общие необязательные поля любого блока:
- `number` — номер упражнения, как в оригинале;
- `instruction_html` — задание с форматированием (жирный, переносы строк), уже очищенное при импорте;
- `pm` — откуда блок взят: тип и id упражнения в ProgressMe.

У `image` вместо одной картинки может быть список: `images: [{src, caption}]`.

В `gaps` пропуск без ключа (`{{}}`) означает свободный ответ. Если таких пропусков в упражнении все, ответы уходят преподавателю на проверку. Если только часть, засчитывается любой непустой ответ.

## Правила проверки

- 3 попытки на упражнение. После каждой попытки верные ответы фиксируются, неверные подсвечиваются.
- После третьей неудачной попытки показываются правильные ответы.
- Сравнение не учитывает регистр, лишние пробелы и вид апострофа (' и ’).
- Балл: 1 за каждый пропуск или вопрос теста, засчитываются только верные.
- Сочинение получает статус «на проверке» и попадает к преподавателю.
