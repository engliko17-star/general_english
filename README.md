# English Platform — версия 1 (переезд с Edvibe)

Что уже работает:
- библиотека учебников;
- плеер урока с упражнениями: текст, картинка, видео, аудио, пропуски, пропуски из списка, тест, сочинение;
- автопроверка, 3 попытки, сохранение результатов;
- черновики в браузере на случай обрыва связи;
- вход по ссылке из письма;
- роли «преподаватель» и «ученик».

Пока не подключена база, сайт работает в демо-режиме. Откройте `index.html` — увидите пример учебника.

## Структура

```
index.html            библиотека и вход
lesson.html           урок
assets/config.js      адрес и ключ Supabase
assets/data.js        работа с базой (и демо-режим)
assets/player.js      упражнения и проверка
assets/app.css        оформление (светлая и тёмная тема)
supabase/schema.sql   таблицы и права доступа
docs/lesson-format.md формат урока
demo/                 демо-учебник
tools/                перенос из ProgressMe: скрипты для консоли и конвертер в SQL
```

## Запуск

**1. База.** Supabase → SQL Editor → New query. Вставьте весь `supabase/schema.sql` и нажмите Run. Скрипт можно запускать повторно, данные он не удаляет.

**2. Ключи.** Supabase → Project Settings → API. Скопируйте Project URL и `anon` `public` key в `assets/config.js`.

**3. Вход по почте.** Supabase → Authentication → URL Configuration:
- Site URL — адрес вашего сайта;
- в Redirect URLs добавьте тот же адрес со звёздочкой в конце, например `https://мой-сайт.ru/*`.

**4. Права преподавателя.** Зайдите на сайт со своей почтой. Затем выполните в SQL Editor:

```sql
update public.profiles set role = 'teacher' where email = 'ваша@почта';
```

**5. Размещение.** Это статический сайт. Папку целиком можно залить на любой хостинг: Netlify, Vercel, Cloudflare Pages, GitHub Pages или ваш нынешний. Сборка не нужна.

**6. Материалы.** Перенесённые уроки придут SQL-файлами. Каждый файл выполняется в SQL Editor так же, как в шаге 1. Повторная загрузка того же урока обновляет его, а не создаёт копию: уроки сопоставляются по `source_ref`.

**7. Назначить урок ученику.** Ученик сначала один раз заходит на сайт со своей почтой. Затем:

```sql
insert into public.assignments (student_id, lesson_id)
select p.id, l.id
from public.profiles p, public.lessons l
where p.email = 'ученик@почта' and l.title = 'Название урока'
on conflict do nothing;
```

Кнопка «назначить» в кабинете преподавателя — следующий шаг разработки.

## Перенос из ProgressMe

1. На любой странице учебника в ProgressMe обновите страницу и откройте консоль (F12 → Console).
2. Вставьте скрипт `pm-export-book` и кликните на любой раздел урока. Скрипт сам пройдёт по всем юнитам, урокам и домашкам и скачает `progressme-book-<номер>.json`.
3. Конвертер превращает файл в SQL:

   ```
   python3 tools/convert_progressme.py progressme-book-1004574.json out/
   ```

   Получатся файлы `progressme-<номер>-partNN.sql` (около 1 МБ каждый) и отчёт `…-report.json`.
4. Выполните SQL-файлы по порядку в Supabase → SQL Editor. Повторная загрузка обновляет уроки, а не создаёт копии.

Что получается:
- учебник ProgressMe становится учебником на платформе;
- юниты становятся разделами библиотеки;
- разделы урока (READING, VOCABULARY…) становятся заголовками внутри урока;
- домашка становится отдельным уроком «… · Homework», чтобы её можно было назначать отдельно.

Заметки и ответы для преподавателя видны только вам. Картинки и аудио пока открываются по ссылкам с серверов ProgressMe. Перенос файлов в хранилище Supabase — отдельный шаг.

Посмотреть урок глазами ученика в демо-режиме: добавьте к адресу урока `&as=student`.

## Как устроен прогресс

Таблица `results` хранит по одной строке на каждое упражнение каждого ученика: ответ, баллы, попытки, статус.

История из Edvibe загружается туда же с пометкой `source = 'edvibe'`. Ученик видит её как выполненные упражнения, но изменить не может.

## Известные ограничения версии 1

- Правильные ответы лежат в самом уроке. Технически подкованный ученик может их увидеть через инструменты разработчика. Позже проверку перенесём на сервер.
- Пока нет экранов, где преподаватель назначает уроки, проверяет сочинения (Inbox) и смотрит статистику по ученикам. Это следующий этап.
- Шрифты и библиотека Supabase загружаются из интернета. Офлайн-режим (PWA) — отдельный этап.
